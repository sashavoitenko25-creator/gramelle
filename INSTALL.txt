LIVE Roulette for Gramelle
==========================

1) Run SQL in Supabase SQL editor:
   sql/roulette_tables.sql

2) Unzip over project root

3) npm run build

Play → LIVE → Roulette

Round machine advances on every /api/roulette/state poll (1s client interval).
Optional: cron POST /api/roulette/process every 2s.
